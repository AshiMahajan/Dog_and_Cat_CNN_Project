What's running

{% if model_name == "basic" %}

A convolutional neural network trained from scratch on the cat/dog dataset — no pretrained weights. Used here as the baseline to measure transfer learning against.

{% else %}

MobileNetV2, pretrained on ImageNet and fine-tuned on this cat/dog dataset. The base network already knows general visual features (edges, textures, shapes); fine-tuning adapts its last layers specifically to cats and dogs — which is why it classifies more accurately than a model trained from zero.

{% endif %}
